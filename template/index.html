Troubleshooting & Engine tips 
• Configured URL: {SERVICE_URL}
• Fast-Path (vector text): Instantaneous (~0.05s/page).
• PaddleOCR fallback: Computer vision for scanned images (~12s/page on CPU).
• Increase SERVICE_TIMEOUT_SECONDS if uploading large scanned PDFs.
• Fast-Path (vector text layer): Instantaneous (~0.02s/page). • PP-OCRv5 Mobile ONNX: Accelerated CPU vision for scanned documents (~15s/page on CPU). • Line baseline merging ensures coherent reading order for typewriter and scanned texts. • Increase SERVICE_TIMEOUT_SECONDS if uploading large multi-page scans.
